# Soccer Team Tracker

A beginner Python project that processes soccer player statistics and calculates individual and team performance.

## About the Project

I created this project to develop my Python programming skills while working with data from a sport I'm interested in.

The program uses a list of soccer players, with each player's name, position, goals, and assists. It processes this information and calculates statistics to evaluate team performance.

## Features

- Calculates total team goals and assists.
- Calculates total goal contributions (goals + assists).
- Calculates the average number of goals per player.
- Calculates individual player contributions.
- Identifies the player with the highest number of goal contributions.

## Technologies Used

- Python 3
- Functions
- Lists and dictionaries
- For loops and conditional statements

## How to Run

1. Download `soccer_statistics.py`.
2. Make sure Python 3 is installed.
3. Open a terminal in the folder containing the file.
4. Run:

`python soccer_statistics.py`

The program will display team statistics, individual player contributions, and the top-performing player.
